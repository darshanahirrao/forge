# Reviewed native schedule controls

Version 0.35 adds a separate [reviewed transfer flow](SCHEDULE_TRANSFERS.md). Resume reviews and already prepared controls respect its persistent source/destination holds, including native profile/listener aliases. Pause remains available, and uncertain native controls must be reconciled before transfer.

Forge adds human review and durable outcome receipts around native scheduler operations. Hermes reuses native `pause_job` and `resume_job` through `hermes-builtin-native-flock/1` on Hermes 0.17.0/source `3aebdb1d2349f1b228aa0478fce2e2fe91827278`. Version 0.33 adds [OpenClaw Gateway controls](OPENCLAW_SCHEDULES.md) with native revision comparison through `openclaw-native-revision/1`. Neither route ticks a scheduler, installs a planner or transfers scheduler ownership. The Hermes-specific lock and definition details below remain distinct from the OpenClaw transaction contract.

In Activity, read a Hermes schedule source, choose Schedules and select **Review pause** or **Review resume**. The review reads the current native job rather than trusting saved inventory. It includes the full bounded job record, native instructions, script reference, rule and next-run observation. Oversized execution content is rejected rather than silently truncated. Confirm that you reviewed the native permissions, delivery and billing, then submit within two minutes. Refresh saved inventory separately when needed; a receipt's observed state is evidence at that action's time.

Pause prevents future scheduling. A job already selected by a native tick, running tools or deliveries can continue. Resume enables future work under Hermes's native provider, permissions, scripts and channels. Forge managed-work budgets, quiet mode and one-time native approval receipts do not govern that separate scheduler. Resume checks Forge's current memory-pressure admission as an additional local gate; it does not impose a permanent native resource ceiling or prevent another native owner starting work.

## Exact review and native ownership

The installed CLI has no expected-revision argument. An unfenced preview followed by that CLI would leave a race. This adapter instead enters Hermes's existing reentrant `_jobs_lock`, verifies that a second descriptor is excluded by an actual OS `flock`, and reads the raw job/configuration bytes under that lock. Before mutation, it reacquires that same native lock and compares both SHA-256 digests and the review deadline. A native change anywhere in the store/config invalidates the review. It then calls the public native operation under the held lock. Nested native load/update/save use the deployed reentrant lock contract.

The preview strictly validates the raw object/jobs shape before any native job loader can repair it. External providers, missing/changed APIs, unavailable cross-process locks, duplicate IDs, malformed content and unavailable acknowledgements do not become success. Configuration parsing reuses the native raw parser and inspects only builtin provider selection; it invokes no resolver/plugin or model. This contract depends on cooperative native writers using Hermes's lock. Same-user hostile filesystem replacement and noncooperating direct file edits are outside that concurrency guarantee.

Controls share the serialized native-source gate with account/inventory operations and managed launch. Source removal cannot race an operation. Review plans bind source identity and canonical home, live only in memory and expire; they cannot survive a Forge restart. The human API requires the existing local/phone authentication and CSRF boundary. Demo and companion bearers have no schedule-control authority. No native approval is fabricated for an agent through this path.

## Failure receipts

Forge saves `submitted` before crossing into the native helper. A confirmed native observation becomes `applied`; a pre-effect definition/contract refusal becomes `rejected`. A timeout, interrupted helper or lost response becomes `uncertain`. Startup converts a previously submitted operation to uncertain and never replays it. Retrying the same receipt ID returns its existing evidence. Unreviewed uncertain/submitted receipts hold another control for that job and prevent forgetting its source.

An uncertain receipt appears in the workspace attention view and Schedules. Check native run history and deliveries, record what you checked, then use **Read state and record review**. Forge reads current native scheduling state and stores the operator, note and observation. A valid native store that no longer contains the exact job can record `not-found`; native removal does not strand the source hold. OpenClaw may report the same native error for a missing or hidden job, so its review records `not-visible-or-absent` and an unknown enabled state. The original uncertain outcome remains uncertain. This releases the control hold without claiming that an earlier effect did not happen or was cancelled. A missing or unsupported profile/lock remains unavailable and requires its native owner to restore an inspectable contract first.

## Evidence and remaining scope

Functional/API tests cover exact binding, idempotency, admission, stale review, source fencing, human authority, pressure refusal and restart uncertainty. Browser tests cover explicit consent, durable receipts, review, both themes/mobile, footer reachability and accessibility. `npm run build && npm run test:native:controls` uses the actual installed native functions with an isolated profile, verifies byte-preserving preview, stale job/config rejection, pause/resume, unavailable lock refusal and an actual owned-helper SIGKILL after the native write. The persisted uncertain result is not replayed. No tick, model or delivery is started.

Codex automations, external Hermes scheduler providers, trigger/create/delete/edit and scheduler ownership transfer require their own supported contracts and conformance. OpenClaw pause/resume now has its separate [native contract and conformance](OPENCLAW_SCHEDULES.md). Current controls do not certify a successful tick or channel delivery.
